# Karty Duel

Online karetní hra pro dva hráče — Prší a Uno. Postavené na Next.js + Supabase Realtime.

Živá verze: https://karty-duel-pied.vercel.app

## Vývoj

```bash
npm run dev
```

Potřebuješ `.env.local` s `NEXT_PUBLIC_SUPABASE_URL` a `NEXT_PUBLIC_SUPABASE_ANON_KEY` (viz `TECHSTACK.md`).
